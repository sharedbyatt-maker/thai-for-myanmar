# ယူနစ် ၁–၅ အတွက် အသံ ဆက်ထုတ်ရန်

အရင် Windows မှာ ထုတ်ခဲ့တဲ့ အသံ ၉၉၀ ဖိုင်ကို app ထဲမှာ ထည့်ပြီးသားပါ။ အဲဒီ ၉၉၀ ဖိုင်ကို ပြန်ထုတ်စရာ မလိုပါ။

လက်ရှိ ယူနစ် ၁–၅ အတွက် အသံချိတ်ဆက်မှု ၁၀၁ ခု လိုပါတယ်။ ၁၆ ခုက အသံဟောင်းနဲ့ တိတိကျကျ ကိုက်ပြီးသားပါ။ ကျန် ၈၅ ခုအတွက် တူညီတဲ့စာသားတွေကို ပေါင်းလိုက်ရင် MP3 အသစ် ၇၉ ဖိုင်ပဲ ထုတ်ရပါမယ်။ ဝါကျအပြည့်နဲ့ စကားလုံးအပိုင်းတွေ ပါပါတယ်။ သင်ရိုး ၂၆ ယူနစ်လုံးကို ရွေးရင်တော့ လက်ရှိ အသစ်ထုတ်ရန် ၄၂၆ ဖိုင် ရှိပါတယ်။

## သင်လုပ်ရမယ့် အဆင့်

1. **Thai_Audio_Studio_Units_1-5.zip** ကို Download လုပ်ပြီး **Extract All** လုပ်ပါ။ ZIP ထဲကနေ တိုက်ရိုက်မဖွင့်ပါနဲ့။
2. Extract လုပ်ထားတဲ့ folder ထဲက **Start_Audio_Studio.bat** ကို double-click နှိပ်ပါ။ Console window ကို ဖွင့်ထားပါ။
3. Browser ပွင့်ရင် **ယူနစ် ၁–၅** ကို ရွေးထားပြီးသား ဖြစ်ပါတယ်။ အရင်အသံနဲ့ တူချင်ရင် **Male: Clear / young (9), Female: Clear / young (2), ပုံမှန် · Normal** အတိုင်း ထားပါ။
4. **နမူနာ ထုတ်မယ်** ကို နှိပ်ပါ။ အသံ ၆ ဖိုင်ပါတဲ့ sample ZIP ထွက်ပါမယ်။ ZIP ကို Download လုပ်၊ Extract လုပ်ပြီး `assets/audio/thai/` ထဲက MP3 တွေကို နားထောင်ပါ။ နမူနာမှာ စကားလုံးနဲ့ ဝါကျ၊ male/female အသံ နှစ်မျိုး ပါပါတယ်။
5. အသံကြိုက်ရင် setting မပြောင်းဘဲ **သင်ရိုးအသံ ထုတ်မယ်** ကို နှိပ်ပါ။ ၇၉ / ၇၉ နဲ့ ပြီးသွားရင် **Audio ZIP download** ကို နှိပ်ပါ။ နမူနာ ၆ ဖိုင်ကို ပြန်မထုတ်ဘဲ ပြန်သုံးပါမယ်။
6. ထွက်လာတဲ့ **thai-course-units-1-5.zip** ကို ဒီ chat မှာ ပို့ပါ။ App ထဲကို ကိုယ်တိုင် ဖိုင်ကူးထည့်ဖို့ မလိုသေးပါ။ Manifest နဲ့ အသံကို စစ်ပြီးမှ ပေါင်းထည့်ပါမယ်။

**အရင် စကားစု ၉၉၀ ဖိုင်ကို ပြန်ထုတ်ရန်သာ** အပိုင်းထဲက **အားလုံးထုတ်မယ်** ကို ဒီတစ်ခေါက် မနှိပ်ပါနဲ့။ အဲဒါက အသံဟောင်း ၉၉၀ ဖိုင် ပြန်ထုတ်ဖို့ ဖြစ်ပါတယ်။

## ရပ်သွားရင်

- Browser နဲ့ console ကို မပိတ်ဘဲ error စာသားကို copy ပို့ပါ။ Screenshot မလိုပါ။
- ရပ်ထား/မပြီးသေးတဲ့ ZIP ကို အပြီးဖိုင်လို မသုံးပါနဲ့။ `generation-report.json` မှာ `status: complete`, `requestedForms: 79`, `readyForms: 79` ဖြစ်ရပါမယ်။ Sample ZIP က ၆ ဖိုင်သာ ဖြစ်ပါတယ်။
- ပြန်ဖွင့်ပြီး တူညီတဲ့ voice/speed နဲ့ **သင်ရိုးအသံ ထုတ်မယ်** ကို ပြန်နှိပ်ရင် cache ထဲက မှန်ကန်ပြီးသားဖိုင်တွေကို ပြန်သုံးပါတယ်။ `build/audio-studio` folder ကို မဖျက်ပါနဲ့။
- Setting ကို စက်ထဲမှာ သိမ်းထားပါတယ်။ Voice/speed ပြောင်းရင် အသံမရောအောင် cache သီးခြားသုံးပါမယ်။

## ကုန်ကျစရိတ်နဲ့ စက်လိုအပ်ချက်

Card/API key မလိုပါ။ Synthesis API မခေါ်ပါ။ Windows x64 CPU ပေါ်မှာ ထုတ်ပါတယ်။ အင်တာနက်ဒေတာနဲ့ လျှပ်စစ်အသုံးတော့ ရှိပါမယ်။ ပထမဆုံး setup/model download လိုနိုင်ပါတယ်။ အရင် Python runtime ကို အလိုအလျောက် ပြန်သုံးပါတယ်။ အသစ် extract လုပ်ထားတဲ့ folder မှာ model မရှိရင် model ၃၃၂ MB ခန့် ထပ် download လုပ်ပါမယ်။ အရင် folder က `build/audio-studio` ကို အသစ် folder ရဲ့ `build/audio-studio` နေရာမှာ ကူးထားရင် မှန်ကန်တဲ့ model/cache ကို စစ်ပြီး ပြန်သုံးနိုင်ပါတယ်။ ဒါက မလုပ်လည်း ရပါတယ်။

အသံဖိုင်အသစ်တွေကို ဒီ pack ပြင်ဆင်ချိန်မှာ မထုတ်ရသေးပါ။ Native Windows launcher ကို ဒီစက်မှာ မစမ်းနိုင်ပါ။ အရင်က အလုပ်လုပ်ခဲ့တဲ့ launcher/model ကိုပဲ ထိန်းထားပြီး scoped planning, sample/full cache reuse, export နဲ့ settings ကို စစ်ထားပါတယ်။ အသံထွက်၊ tone နဲ့ ယဉ်ကျေးအဆုံးသတ်ကို နားထောင်စစ်ပြီးမှ public app ထဲ ထည့်ပါမယ်။
