## Full description

ထိုင်းနိုင်ငံမှာ အလုပ်လုပ်၊ နေထိုင်၊ သွားလာတဲ့ မြန်မာစကားပြောသူတွေအတွက် နေ့စဉ်သုံး ထိုင်းစကားစုတွေကို မြန်မာလို လေ့လာပါ။

နှုတ်ဆက်စကား၊ ဈေးဝယ်ခြင်း၊ စားသောက်ဆိုင်၊ သွားလာရေး၊ အလုပ်ခွင်၊ ဆေးခန်းနဲ့ နေ့စဉ်အခြေအနေတွေမှာ အသုံးဝင်တဲ့ စကားတွေကို အလွယ်တကူ ရှာနိုင်ပါတယ်။ ထိုင်းစာ၊ မြန်မာအဓိပ္ပာယ်၊ မြန်မာလို အနီးစပ်ဆုံးအသံထွက်ကို တစ်နေရာတည်းမှာ ကြည့်ပြီး ရနိုင်တဲ့စက်မှာ ထိုင်းအသံကို နားထောင်ပါ။

**အဓိကလုပ်ဆောင်ချက်များ**

- အင်တာနက်မလိုဘဲ စကားစုရှာဖွေ၊ လေ့လာ၊ Quiz ဖြေဆိုနိုင်ခြင်း
- မြန်မာ၊ ထိုင်း၊ အင်္ဂလိပ်စကားလုံးများဖြင့် ရှာဖွေနိုင်ခြင်း
- အမြန်ပြောရန် စာကြောင်းကို ပြပြီး အသံထွက်နားထောင်နိုင်ခြင်း
- အသုံးများတဲ့ စကားစုတွေကို အကြိုက်ဆုံးအဖြစ် သိမ်းနိုင်ခြင်း
- အလင်းရောင်နှင့် အမှောင်ပုံစံ၊ ကိုယ်ပိုင်လေ့လာမှုမှတ်တမ်း
- အကောင့်ဖွင့်ရန် မလိုခြင်း

အသံထွက်နဲ့ စက်ရဲ့ TTS ပံ့ပိုးမှုက ကွဲပြားနိုင်ပါတယ်။ ကျန်းမာရေး၊ ဥပဒေ၊ အလုပ်စာချုပ်နဲ့ အရေးပေါ်ကိစ္စတွေမှာ စကားစုတွေကို အချက်အလက်အဖြစ်သာ သုံးပြီး ကျွမ်းကျင်သူ သို့မဟုတ် စကားပြန်နဲ့ အတည်ပြုပါ။
