# Path-first UI

The reference screenshot motivates a compact status strip, a single pinned unit
banner and a visual lesson path. This app retains its own elephant, indigo palette
and original icons. No hearts, currency balances or copied proprietary assets are
introduced.

Learn shows streak, XP and daily progress as three tappable counters. Rank badges
and daily-goal settings open on demand. The unit banner contains topic selection
and one continue action; the repeated first-topic card and large introductory
cards are removed. Lesson captions appear only on the current lesson; all nodes
retain full accessible names and remain unlocked. The continuous 112-lesson path
and topic jumping are preserved.

Everyday opens directly into search and visual categories. Review uses a smaller
mascot and one short heading. Mobile navigation labels appear on the selected tab,
while all destinations retain their accessible labels. Existing audio and local
learning progress are unchanged.
