# App audit — 2026-10-31

Scope: the existing Thai for Myanmar application, based on main `34306a1`.
The audit covers lesson/review scheduling, local preferences and progress,
search/favorites, Thai playback, responsive layouts, League request/session
handling, bundled content/audio, database privacy and release workflows.

## Fixes

- Preserve an acknowledged League board when a refresh fails. An initial
  failed request no longer implies that the account needs to join again.
- Clear account-bound board state on auth changes and discard a board response
  started before the auth change, rather than applying stale account state.
- Bound join/leave requests to 20 seconds, consistent with other League RPCs.
  A timed-out server write may still complete; refreshing retrieves its state.
- Return to the top for each League question and the acknowledged score screen,
  so short screens do not retain the previous question's bottom scroll offset.
- Share a scrollable full-screen translation dialog between phrase details and
  Quick Speak. Long Thai/Myanmar text, enlarged fonts and short landscape
  screens keep the playback and close controls reachable. Closing the dialog
  stops its audio.
- Correct Settings and the privacy implementation draft: local learning is
  device-bound; optional Google League login stores identity and competitive
  records on Supabase. Opt-out is not account deletion or cloud progress sync.

## Verification

- 125 Flutter unit/widget tests passed, including five new regression cases.
- Dart analysis: no issues; formatting and whitespace checks passed.
- Real PostgreSQL tests (PGlite) passed catalog, private access, group capacity,
  account checks, scoring, retries, daily cap, opt-out and week rollover.
- 16 Python content/audio-tool tests passed. Failure-path tests deliberately
  simulate ONNX and memory errors; they are not production failures.
- Structural content: 502 phrases / 35 categories / 112 lessons.
- Bundled audio: 990/990 selected forms mapped, none missing; no audio files or
  translations were regenerated or changed.
- PyThaiNLP audit: 1,478 forms checked, zero hard errors and six suggestions for
  human editorial review. Automated checks do not certify native fluency.
- Hosted read-only SQL: 502 questions, seven RLS-protected private tables, zero
  direct client table grants and zero public SECURITY DEFINER League functions.
- Hosted performance advisors: no findings. Security advisors retain seven
  intentional deny-all private-table INFO notices and the existing leaked-
  password-protection warning. Google-only app login does not handle users'
  Google passwords; no paid-plan/security-policy changes were made.

CI additionally verifies mobile/desktop browser flows and Android builds/emulator
flows before merge. The release is complete only after its specific Render
production deployment is live and the public site is checked.

## Limits and follow-up requiring another environment or human review

Physical-device Android Google OAuth and native iOS release/signing remain
unverified. Google Play signing, production ads/consent and an owner-published
privacy policy are separate release work. Independent fluent Thai–Myanmar and
native listening review remains necessary. The browser preview does not promise
reliable offline reload; installed Android assets provide the offline path.

No fake competitors, paid infrastructure or new backend projects were created.
No existing user progress or server memberships were deleted during the audit.
