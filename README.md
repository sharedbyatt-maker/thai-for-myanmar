# Thai for Myanmar

Practical, offline-first Thai for Myanmar speakers living, working, studying, or travelling in Thailand. Android is the primary V1 product; the same Flutter UI also builds as a browser preview for owner review on an iPhone or PC.

## V1 snapshot

- **502 phrase records across 35 categories**, with Thai text, Myanmar meaning, Myanmar-readable pronunciation, English meaning, keywords, and situation tags.
- Home, Learn, Situations, Quick Speak, Search, Favorites, Quiz, Light/Dark/System theme, and persisted local progress.
- Guided five-phrase lessons, flashcards, meaning/listening questions, matching, sentence-piece practice, due/new/difficult/favorite filters, daily goals, streaks, and seven-day learning history. Listening earns no progress when Thai audio is unavailable.
- Bundled lessons, search, favorites, quiz, and progress work without an account or network connection after install.
- Thai playback is asset-first when a matching bundled recording exists, with verified Thai-only device/browser TTS as the fallback. A non-Thai default voice is never used. The bundled generated audio pack covers all 990 selected forms; independent human listening review remains pending. See [audio pack details](docs/BUNDLED_AUDIO.md).
- Settings includes a Thai voice test and platform-specific setup guidance. Phrase details accept correction reports saved only on the device, with a copy action for sending through the user's chosen app. Saving a report does not transmit it.
- AdMob support is centralized and **disabled by default**. Debug test ads can be enabled explicitly. No production identifiers are included.
- Content and structural validation pass, and an editorial pass checked meaning alignment, natural question phrasing, gendered Thai particles, and Myanmar-readable pronunciation. Independent fluent Thai–Myanmar review is still needed before broad public release, particularly for high-risk workplace, medical, police, immigration, and employment phrases.

## Run and build

Install Flutter stable and Java 17. From the project folder, generate the platform files once, then run the app:

```sh
flutter create . --platforms=android,web --org=com.sharedbyatt --project-name=thai_for_myanmar
python3 tool/configure_android.py
flutter pub get
flutter run -d chrome
```

For Android, connect an emulator or use an Android device, then run `flutter run`. To build a test APK, use `flutter build apk --debug`. To build a release-mode App Bundle, use `flutter build appbundle --release`; production signing is deliberately not configured in this repository.

Run the checks with:

```sh
python3 tool/validate_content.py
dart format --output=none --set-exit-if-changed lib test
flutter analyze --fatal-infos
flutter test
```

## AdMob safety

Ads are off unless `ENABLE_ADS=true` is passed at build time. A debug build uses Google's public test banner unit only. Release builds show ads only when `ADMOB_PRODUCTION=true` and a real Android banner unit ID is supplied. The Android manifest generated by `tool/configure_android.py` contains Google's public **test app ID**; replace it with an owner-issued production app ID only when preparing a Play release. No ad or ad-load failure appears in Quick Speak or Emergency.

## No-card Thai Audio Studio (Windows)

Download/extract this repository ZIP and double-click **Start_Audio_Studio.bat**. It prepares a private Python environment and opens a local browser UI for Thai Kokoro voice previews, the nine-file sample, all 990 phrase/form MP3s, progress/stop controls, and ZIP download. First setup downloads Python/packages and about 332 MB of verified model files. No Google account, card or synthesis API key is required. The app audio manifest is unchanged until the generated pack is reviewed and imported.

See [Local Audio Studio setup and limitations](docs/LOCAL_AUDIO_STUDIO.md). Windows launcher execution still needs native Windows verification; the real CPU engine and nine-file MP3 pack have been tested on Linux.
