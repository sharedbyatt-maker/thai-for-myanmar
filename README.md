# Thai for Myanmar

A practical, offline-first Thai learning app for Myanmar speakers living, working, studying, or travelling in Thailand.

Android is the primary V1 platform. The project uses Flutter and keeps phrase content in a validated, versioned dataset. No production ad identifiers, signing keys, or user credentials are stored in this repository.

The app is being built on a feature branch. See the project documentation for setup, content, privacy, testing, and release preparation.
